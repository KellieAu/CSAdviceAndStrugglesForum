# CSAdviceAndStrugglesForum

A website that can take anonymous struggle stories from students, as well as general advice as a CS major. This would be something that is accessible to everyone to submit as well as view. Able to submit both general and class-specific advice.

## Setup

1. Install Python 3.8 or higher.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open http://127.0.0.1:5000 in your browser.

## Features

- Anonymous submissions of struggle stories and advice.
- Categories: General or class-specific.
- View all posts on the home page.
- Click on a post to view full content.

## Technologies

- Flask
- SQLAlchemy
- WTForms
- Bootstrap
